# PyCodeBite

**PyCodeBite** is an interactive, pocket-sized web application designed to help learners master Python programming through practical lessons, logic-testing quizzes, and a structured curriculum.

## Live Demo
Check out the live application hosted on Streamlit Cloud: [PyCodeBite Live App](https://pycodebite-kti2jemoushxaxeu2wgqpw.streamlit.app)

## Features
* **Interactive Lessons**: Master core Python concepts like variables, loops, and data structures.
* **Quizzes & Scoring**: Test your knowledge and track your progress in real-time.
* **Clean UI**: Built with Streamlit for a fast, responsive user experience.
